API keys

Stored in localStorage on this device, calls go straight from your browser to Claude (claude-sonnet-4-6) first, then Groq (llama-3.3-versatile) if that fails. That's fine for a personal tool on your own device, but it's not secure for anything public — anyone with access to this browser's storage could read the keys. Don't reuse this file for a shared or public deployment without putting a backend between the browser and the API.
